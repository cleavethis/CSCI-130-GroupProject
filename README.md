This README.md file is a Gruop project creating our own version of wordle for our class in CSCI130. This Wordle project has multiple layers containing multiple files
There is a required implementation for the project:
  Client: HTML, CSS, and JavaScript Wordle Interface and game logic
  Server: Word dataset API, authentication, statistics, and leaderboard enpoints
  Database: Users, game sessions, and persistant player statistics
  Pages: Home, rules, creator, game, login, or registration, and leaderboard
  Core Limit: Six Guesses for each five-letter target word
